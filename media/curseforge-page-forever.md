# CurseForge project page — FarmBuddy: Forever (copy/paste)

## Name
FarmBuddy: Forever

## Summary
Classic zone mob database for FarmBuddy on WoW: Forever. Requires FarmBuddy.

## Description

**FarmBuddy: Forever** is an extension for **FarmBuddy** that adds the classic zones to the Mob Map on **WoW: Forever**.

FarmBuddy only shows mobs on the Mob Map when they are in its mob database. The base addon ships the Retail zones only, so Retail players don't carry classic data they will never use. Install this extension next to FarmBuddy to map the farmable mobs of the classic zones.

### Requirements
- **FarmBuddy 1.9.0 or newer** (required dependency)
- WoW: Forever client

### Zones
- **Kalimdor:** Teldrassil, Mulgore, Durotar, Darkshore
- **Eastern Kingdoms:** Dun Morogh, Elwynn Forest, Tirisfal Glades, Loch Modan, Westfall
- **New in Forever:** Zephras Isle

More zones are added in each update. Mobs currently show type icons (Beast, Humanoid...) on the map; 3D portraits will come in a future update.

### How it works
Nothing to configure. With both addons enabled, open the FarmBuddy Mob Map and farm as usual. Mobs from the supported zones are logged automatically from nameplates and mouseover.
